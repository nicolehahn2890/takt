# Schritt 4: Atem-Modus, Seitenwechsel, Fertig-Screen, lernende Dauer, Abzeichen, Tagebuch, Backup – Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Takt führt durch Atem-Übungen und Seitenwechsel, zeigt nach dem Training eine Zusammenfassung mit Notiz, lernt Wunsch-Dauern, sammelt Abzeichen, führt ein Tagebuch und kann alles als Datei sichern und wieder laden.

**Architecture:** Neue reine Logik mit Node-Tests: Seitenwechsel als Engine-Ereignis `side`, Atem-Töne als Funktion über die verstrichene Schrittzeit, lernende Dauer (`js/learn.js`), Abzeichen (`data/badges.js` + `js/badges.js`), Backup schreiben/lesen (`js/backup.js`). Die Oberfläche hängt sich an bestehende Stellen: Training (`app.js`), Fertig-Screen (`index.html` + `app.js`), Statistik-Seite (`statsview.js`), Editor-Speichern (`editor.js`), Fotos (`photos.js` bekommt Export/Import).

**Tech Stack:** wie bisher (Vanilla JS an `window.Takt`, `node tests/run.js`, Web Audio, IndexedDB, Design v2).

**Spec:** `docs/superpowers/specs/2026-10-24-schritt-4-design.md` (inkl. Abschnitt „Nach der Bau-Prüfung geklärt“)

## Global Constraints

- Keys `takt_v1`, `takt_run_v1`, IndexedDB `takt_photos_v1` nie umbenennen; alte Daten bleiben lesbar (fehlende Felder = Standard).
- `js/` nur ASCII (`python tools/ascii_js.py`); kein `backdrop-filter`; Überschriften unter `--glass-top`; Design-Werte aus `docs/design_handoff_takt_redesign/`; keine Icons/Emojis, nur Text, Zahlen und Zeichen; Knöpfe Radius 14, Tippziel ≥ 44 px.
- Keine neuen Katja-Dateien; vorhandene Clips `side`, `left`, `right` nutzen.
- Bei jedem Push mit geänderten App-Dateien `?v=` hochzählen (Start: `v=32`).
- GitHub nur Privatkonto (`nicolehahn2890/takt`), Push mit Privat-Token, danach `git status -sb` = „main...origin/main“, nichts offen.

## Review Focus

1. **Töne überlagern sich:** beidseitige Übung 20–26 s mit „Noch zehn Sekunden“, Atem-Übung direkt nach Namensansage, 3-2-1 bei Atem, Rückkehr aus dem Hintergrund mitten im Atmen: nie zwei Ansagen gleichzeitig, kein Ton-Stau. Tests in Task 1 und 2.
2. **Backup laden mit kaputter oder fremder Datei** (kein JSON, falsche App/Version, ungültige Einträge, fehlendes Foto, Speicher voll): gute Daten bleiben unangetastet oder es wird nach Rückfrage geladen, nie halb. Tests in Task 6, Browser in Task 6.
3. **Lernende Dauer fragt falsch:** gemischte Richtungen, Anpassen-Läufe, Wiederholungsrunden, gelöschte Übung, Vorlage, Mix, gerade zurückgestellt: keine Frage oder die richtige. Tests in Task 4.
4. **Abzeichen doppelt oder verschwunden:** Nachtragen beim ersten Start ohne Feier, jedes Abzeichen nur einmal gefeiert, bleibt nach Löschen erreicht, Serien über Monats-/Jahresgrenze. Tests in Task 5.
5. **Neuladen mitten in einer beidseitigen oder Atem-Übung:** Seite und Atemphase stimmen nach dem Wiederherstellen, kein doppeltes „Seite wechseln“. Tests in Task 1 und 2.

### Task 2: Atem-Modus

**Files:** Create `js/breath.js`; Modify `js/announce.js` (Atem: kein warn/count), `js/audio.js` (Töne `in`/`out`), `js/app.js` (großer Atemkreis statt Ring, Töne aus der Schrittzeit), `index.html`, `css/app.css`, `tests/breath.test.js`, `tests/announce.test.js`, `tests/run.js`

**Interfaces – Produces:** Die Atem-Uhr einer Übung beginnt `startDelayMs` (2000) nach Schrittbeginn (Zeit für die Namensansage); davor bleibt der Kreis klein (`k = 0`). `Takt.breathClock(elapsedMs, startDelayMs) -> ms` (≤ 0 vor dem Start); `Takt.breathCues(atem, fromMs, toMs, startDelayMs) -> [{ atMs, tone:'in'|'out' }]` = Phasenanfänge von „ein“ (`in`) und „aus“ (`out`) der verschobenen Uhr im halboffenen Intervall `(fromMs, toMs]` der Schrittzeit (ein Anfang genau bei `startDelayMs` zählt, wenn `fromMs < startDelayMs`). Das Training ruft sie je Takt mit voriger und jetziger Schrittzeit auf und spielt höchstens den letzten Ton (verpasste werden nicht nachgeholt); der Kreis nutzt `breathAt(atem, breathClock(...))`.
**Aussehen:** Bei Atem-Übungen ersetzt der Kreis den Ring in gleicher Größe: Kreis Lavendel 18 % Füllung, Rand Lavendel, wächst mit `breathAt(...).k`; Mitte: Phase („Einatmen“ …) Outfit 24 px, Sekunden der Phase 40 px; darunter „noch 2:30“ 13 px muted. Das kleine Figurenfeld zeigt bei Atem-Übungen nichts zusätzlich.

- [ ] Failing tests: `breathCues Rhythmus 4-4-4-4` (Schrittzeit 0–20 s → `[in 2000, out 10000, in 18000]`); `breathCues ohne Halten` (4-0-6-0, 0–20 s → `[in 2000, out 6000, in 12000, out 16000]`); `breathCues vor Start keine` (0–1999 → `[]`); `breathClock` (1000 → ≤ 0, 5000 → 3000); `announce Atem ohne warn und count`
- [ ] FAIL → umsetzen → grün; Browser: Atem-Übung im Training (Kreis wächst/schrumpft, Phasen-Text, Töne laut Konsole-Protokoll); Commit `Schritt 4: Atem-Modus`, Push, synchron prüfen
